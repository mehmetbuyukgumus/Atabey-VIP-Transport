# VIP Transport Next.js

This project is built with **Next.js**. Follow the instructions below to run it locally.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed  
- A package manager: **npm** (comes with Node.js) or **yarn**

### Installation & Running
```bash
# Clone the repository
git clone https://github.com/mehmetbuyukgumus/Atabey-VIP-Transport.git
```

# Navigate into the project directory
```bash
cd vip-tansport-nextjs
```

# Install dependencies
```bash
npm install
# or
yarn install
```

# Start the development server
```bash
npm run dev
# or
yarn dev
```

This project uses the `public` folder for media files (images, videos, etc.). If it doesn’t exist, create it manually.

1. Create a folder named `public` in the root directory  
2. Add your media files to this folder  
3. Ensure file names and paths match those used in the project  

**Example files:**
- `car3.jpeg`  
- `car4.jpeg`  
- `banner1.mp4`  
- `mercedes_s.jpeg`  

⚠️ If you use different file names or paths, update the project code accordingly.
